# Research programs

Programs are stable areas of investigation. They group related questions and inquiries without serving as roadmap stages, maturity buckets, or authority domains.

| Program | Area of investigation |
| --- | --- |
| [Fourth Edition Architecture](fourth-edition-architecture/README.md) | Canonical semantic compiler architecture and compiler-backed tooling. |
| [Regex Knowledge Architecture](regex-knowledge-architecture/README.md) | Modeling and maintaining comprehensive regex knowledge without duplication. |
| [Regex Conformance Science](regex-conformance-science/README.md) | Experimental methodology, reproducibility, discrepancy handling, and certification. |
| [Portability & Compatibility](portability-compatibility/README.md) | Rigorous cross-system, cross-version meaning of portability and compatibility. |
| [Regex Analysis & Explanation](regex-analysis-explanation/README.md) | Analysis, witnesses, repair, safety, migration, and explanation. |
| [Regex Reference](regex-reference/README.md) | Information architecture for a definitive evidence-backed public reference. |
| [Regex Lab](regex-lab/README.md) | Public Audit, Evaluate, Compare, and Playground research. |
| [Adoption & Ergonomics](adoption-ergonomics/README.md) | Maintainability, workflow, embedded tooling, adoption, and migration. |
| [Beyond Regex](beyond-regex/README.md) | Long-range generalized pattern questions without product commitment. |
| [Beyond Patterns](beyond-patterns/README.md) | Focused symbolic representation, relational matching, bounded discovery, evidence, and computational-boundary research. |

An inquiry may belong to multiple programs. Each assignment appears in inquiry frontmatter and in the related program READMEs. Future questions stay in program READMEs until actual inquiry work begins.

Beyond Regex remains the broad umbrella for grammar, recursive, approximate, AI, goal-directed, non-text, and generalized-system questions. Beyond Patterns is a focused program within that long-range space; it does not supersede Beyond Regex or create an implementation sequence.
