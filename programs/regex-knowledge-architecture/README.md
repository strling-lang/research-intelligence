# Regex Knowledge Architecture

## Purpose

Research how comprehensive regex knowledge should be modeled, maintained, queried, versioned, and connected to evidence without duplicating the operational STRling Regex Knowledge Program.

## Important research questions

- Which entities and relationships make engine, dialect, implementation, host, API, Unicode, replacement, option, and version distinctions explicit?
- How should unknowns, conflicts, historical claims, and coverage completeness be represented?
- How should normative knowledge reference empirical observations without copying their authority?
- What publication projections can be generated from canonical knowledge without losing provenance?

## Relationship to STRling

The compiler and public reference need trustworthy knowledge projections. This program can evaluate architectures and implications, but downstream owners decide and implement integrations.

## Current evidence boundary

The [Knowledge Program](https://app.notion.com/p/3ba7d940647581a9b60dd76f67e5230e?pvs=204) currently defines a graph of versioned profiles, features, capabilities, relations, claim-level evidence, and coverage facets. It is on hold pending reassessment against Regex Conformance. That workspace remains the operational knowledge authority while retained; no database is copied here.

## Related existing inquiries

No current inquiry is dedicated to this question. Registry and structural-contract material inside the semantic validation inquiry may offer historical design input but is not a canonical knowledge model.

## Future research opportunities

- authority-preserving Knowledge–Conformance linkage;
- stable identifiers and schema evolution;
- completeness and conflict-resolution models;
- repository-backed versus operational-workspace tradeoffs; and
- public projection and query requirements.

## Explicit non-goals

This program does not populate regex feature, system, profile, capability, evidence, relation, or coverage databases and does not resume the paused Knowledge Program.
