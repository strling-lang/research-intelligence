# Research report metadata

Place a compact metadata block below an imported or generated report's title. Omit optional fields that do not apply.

```text
Role: Historical research input | Research report | Literature review | Experiment report | Provisional synthesis
Origin: Author, organization, tool, or import source
Published/Generated: YYYY-MM-DD or original publication date
Imported: YYYY-MM-DD
Source verification: Unreviewed | Partially verified | Verified under current evidence standard
Last reviewed: YYYY-MM-DD
Current status: Active input | Historical input | Superseded | Retracted | Provisional
Superseded by: Relative link or durable URL
```

Metadata records provenance and review state. It does not make the report authoritative, certify its sources, or replace inquiry frontmatter.
